# Mission: React and the browser DOM

## Why

Build React applications with confidence by understanding what the browser owns, what React owns, and when component code runs.

## Success looks like

- Predict the order of state updates, renders, DOM commits, browser paint, and Effects
- Choose between event handlers, `useEffect`, `useLayoutEffect`, and refs from first principles
- Diagnose extra renders, stale Effects, DOM ownership conflicts, and visible layout glitches
- Use browser and React profiling tools to verify a runtime explanation

## Constraints

- The learner already builds full React applications
- Lessons combine short explanations, hands-on tasks, theory, and primary sources
- Start from DOM fundamentals without repeating general JavaScript or HTML syntax

## Out of scope

- React Native rendering
- Server Components and framework-specific rendering until the client model is firm
- React reconciler implementation details that do not improve application debugging
