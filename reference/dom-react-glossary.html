Quick reference

DOM and React glossary

Use these terms precisely when explaining runtime behavior.

Browser model

HTML source
Text that the HTML parser reads. It is input to DOM construction, not the live page object.
DOM
A browser API that represents a document as objects arranged in a node tree.
Node
An object in a DOM tree. Common node types include Document, Element, Text, and Comment.
Element
A DOM node representing an HTML or SVG element. An element can own attributes and child nodes.
Paint
A browser step that turns layout and style results into pixels. A DOM change and a paint are related but not identical events.
EventTarget
A DOM object that can receive events and hold listeners. Element, Document, and Window are EventTargets.
Event
An object the browser dispatches to describe something that happened, such as a click. event.target is the node where it started.
Task
A unit of JavaScript work on the event loop. A click listener run and a setTimeout callback are tasks.
Microtask
Work that runs after the current task finishes and before the browser paints. Promise then callbacks are microtasks.
Event loop
The browser loop that runs one task, then all waiting microtasks, then may paint, then repeats.

React model

React element
A JavaScript description of UI. JSX creates React elements; it does not create DOM nodes by itself.
Root
The object returned by createRoot(domNode). React manages DOM inside that node after root.render.
Trigger
The reason React will call components: the first root.render, or a state update such as setState from an event.
Render
React calls components to calculate the next UI description. Render should not mutate the DOM.
Commit
React applies the required changes to its host environment. In a browser React root, the host environment is the DOM.
Effect
Synchronization between React state and an external system. An Effect starts and stops synchronization after relevant commits.
State snapshot
The state values React gives a component for one render. Event handlers from that render keep seeing those same values, even if a setter already ran.
Batching
React processes several state updates from one event as one later render, not as several immediate DOM writes.
Updater function
A function passed to a setter, such as n => n + 1. React applies it to the queued state, not to the snapshot from the current render.
Ref
A stable object whose current value can hold data outside rendering, including a DOM element managed by React.
Sources: MDN DOM, WHATWG DOM Standard, and React: Render and Commit.
