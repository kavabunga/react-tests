Trigger, render, commit

A screen update is three React steps, then a browser paint. Rendering is calling your function. The DOM changes only at commit.

The gap from Lesson 3

Look at your src/main.tsx as two different values:

createRoot(document.getElementById("root"))  // DOM node: the container
  .render(<App />);                            // React element: the description

createRoot takes a live DOM node. React will own what goes inside it. root.render takes a React node (JSX / a React element), not a DOM node. You already found the container: #root.

Three React steps, then paint

1 · Trigger Why render now

First root.render, or setState from a click task.

2 · Render Call components

React calls your function. It returns new descriptions. Do not change the DOM here.

3 · Commit Patch the DOM

React applies the smallest DOM updates that match the new tree. Then the browser may paint.

Official wording: rendering is React calling your components. After that, React commits to the DOM, then the browser paints. Render and Commit.
