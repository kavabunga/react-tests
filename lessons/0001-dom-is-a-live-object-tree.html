Lesson 1 · DOM foundations · 10 minutes

The DOM is a live object tree

Separate HTML text, DOM objects, and painted pixels. React only makes sense after these are separate in your mental model.

Tangible win By the end, you can inspect one page value and say whether it is HTML source, a DOM node, or pixels.

Three things, not one

1 · HTML Text input

The browser parses markup such as <button>.

2 · DOM Objects in memory

The parser creates connected Element and Text nodes.

3 · Screen Painted pixels

The browser uses the DOM and CSS to calculate layout and paint.

The DOM is not HTML and it is not JavaScript. It is a Web API supplied by the browser. JavaScript can hold references to DOM objects and call their methods. 

const button = document.querySelector("button");

button instanceof HTMLButtonElement;
true

typeof button;
"object"

button is a JavaScript variable. Its value refers to a browser-created DOM object. Changing that object can change the next pixels the browser paints.

What this changes in React

      

        JSX does not return DOM nodes. It creates React elements: JavaScript descriptions of the UI
        React should produce. React later commits DOM operations that make the browser document
        match those descriptions.
      


      
const description = <button>Save</button>;

description instanceof HTMLButtonElement;
false
